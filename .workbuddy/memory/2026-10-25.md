## 本轮修掉的 3 个真 bug（都是自己之前写的）

1. **数据目录顺序（严重）**：`electron/main.js` 第 22 行 `require('../server/config.js')` 早于第 50 行
   `process.env.CHAOS_DATA_DIR = ...`。config 在加载时就把 DATA_DIR 算成 `ROOT/data`（安装目录），
   等于「搬到 userData」白写。修法：把环境变量赋值提到所有 `server/*` require 之前。
   真机验证 `/api/system.dataDir` = `C:\Users\Andy\AppData\Roaming\chaos-console\data`。
   审计加断言：`indexOf('process.env.CHAOS_DATA_DIR =') < indexOf("require('../server/config.js')")`。
2. **工作区相对路径校验被架空**：先 `path.resolve(raw)` 再 `path.isAbsolute(abs)` → 永远为真。
   改为先校验 `raw`。现在 `relative/nope` 返回 400。
3. **`ink-950` 不存在**：Tailwind 配置里 ink 只有 400~900。`bg-ink-950/95` 是无效类名 →
   手机号闸门遮罩透明、ErrorBoundary 的 stack 框没底色。统一改 `ink-900`。审计加 `mustNot(/ink-950|bg-ink-950/)`。

## 环境坑（本机）

- 本机 `HTTP_PROXY/HTTPS_PROXY=127.0.0.1:49616`，curl 访问 localhost 会报
  `upstream connect failed`。**必须加 `--noproxy '*'`**，起服务前 `unset` 代理变量。
- 起后端必须用 `run_in_background=true`，`nohup ... &` 会随 shell 退出被杀。
- Git Bash 会把 robocopy 的 `/E` 当路径转换 → **robocopy 走 PowerShell 工具**。
- `Start-Process -RedirectStandardOutput` 在 http_proxy/HTTP_PROXY 同时存在时报
  「已添加项。字典中的关键字」，改用 explorer.exe 或直接 `&`。
- 鉴权头是 `x-chaos-token`（不是 Authorization）；`POST /api/login` 空 body 就发 token。
- Electron 侧 `--remote-debugging-port` 的 HTTP `/json` 端点在本机被挡（打印的 ws 地址可用连），
  且 `CHAOS_E2E=1` 实例与正式实例共享 userData 会抢磁盘缓存 → `ERR_FAILED (-2)`，别同时跑。

## 9.8.0 收尾验证（同日补）

- **SSE 被吞的真凶**：body-parser 读完请求体后 `req` 就 emit `close`，
  监听 `req.on('close')` 会把 `closed` 立刻置 true，后续 `write()` 全部 return。
  必须监听 **`res.on('close')`** + `req.on('aborted')`。
- **pollinations 免费额度是「每 IP 每 45 秒 1 张」**，并发 3 路抢同一 IP 会有 2 张
  直接 402 FREE_LIMIT。改成 `enqueueOnline()` 全局排队 + 成功后主动推后 46 秒，
  拿到 402 时读 `Retry after Ns` 再等。3 张图约 165s，但 **3/3 都是真图**
  （之前是 1 真图 + 2 本地插画，用户看到「生成 3 张」成品只有 1 张）。
- **配图只能给有图位的版式**：`addImage` 只在 cover / bullets 出现，
  但 `pickImageJobs` 原来不判 kind，`twocol` 页的图白生成、渲染时无处可放。
  已加 `IMAGE_KINDS = Set(['cover','bullets'])` 过滤 + 用空图要点页补位。
- **`/api/system` 返回 `{ok, data}` 包装**，直接读 `j.version` 全是 undefined，
  要读 `j.data.chaos`。
- **专家中心空白根因**：`chaosLlm.summary()` 不含 experts，前端读
  `system.chaos.experts` 永远为空 → index.js 里补
  `{...summary(), experts: EXPERTS.map(...)}`（8 个专家）。
- **warmUp 误判引擎未安装**：`probe()` 只回 `{up, models, version}`，没有 `installed`；
  要用 `ollamaBin()` 判引擎、`catalogFor(s.models)` 找已装模型。
- 任务时长改成看门狗：`RUN_TIMEOUT=0`（不限总时长）+ `RUN_IDLE_TIMEOUT=15min`
  空转兜底，`onDelta` 里 `watchdog.arm()` 续期。
- 本轮验证：审计 210/210、regress 50/50、regress:v8 64/64、i18n 333/333、
  AIPPT e2e 6 页 2/2 真图、重渲染 50ms 全缓存命中。

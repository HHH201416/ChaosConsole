## 新增功能：运行期间禁止关机（用户 16:44 提出）

**需求**：应用运行时不允许关机，设置里可开；点关机时显示「ChaosConsole 不允许关机」并自动取消。

**关键限制**：Electron 在 Windows 上只有 `session-end`，那是系统**已决定**结束会话之后的通知，
没有 preventDefault；`before-quit` / `will-quit` 在关机时**根本不触发**（electron.d.ts 明写）。
唯一能拦住的是 WM_QUERYENDSESSION 返回 FALSE —— 必须有原生窗口过程。

**实现**（`electron/shutdown-guard.js`）：用系统自带的 .NET Framework 经 Add-Type 现编一个隐藏窗体
（约 1 秒），WndProc 里：
- `WM_QUERYENDSESSION` → 写 blocked.flag + 调 `AbortSystemShutdown`（有权限就真撤掉）+ `m.Result = 0`
- `ShutdownBlockReasonCreate(hwnd, "ChaosConsole 不允许关机")` —— 这句就是 Windows 阻止清单里给用户看的话
三层防护：隐藏窗体主路径 → SystemEvents.SessionEnding 兜底（编译失败时）→ 主进程
`session-end` 里跑 `shutdown /a`。

**必须做对的几件事（都会出事故）**：
- 退出应用要收掉守护：`before-quit` 的 finalizing 分支第一步 `stopShutdownGuard()`（因为下面走
  `app.exit(0)`，不发 will-quit）、`will-quit`、`process.on('exit')` 三处都收。
- 父进程没了守护要自杀：C# 里定时 `Process.GetProcessById(parentPid)`。**已实测**：强杀父进程后
  3 秒内守护自行退出，不会留下「关掉应用反而关不掉机」的孤儿。
- PS1/CS 文件必须带 UTF-8 BOM，否则 PS 5.1 按 ANSI 读，中文全乱码。
- PS 5.1 一旦显式给 `-ReferencedAssemblies`，默认引用就不全 → 必须把
  System/Core/Windows.Forms/Drawing 点齐；编不过再退「先 Add-Assembly 再 Add-Type -Path」。

**配置链路**：`blockShutdown` 设置（默认关）→ `/api/settings` 读写 → store bus `settings:updated`
→ 主进程 `syncShutdownGuard()` 立刻生效（不用重启）→ 界面 `ShutdownGuardField` 通过 IPC 问
**真实状态**（running / running-fallback / starting / error / unsupported），不拿设置值当结果。

**验证**：`npm run test:shutdown-guard` 自检**通过**（往守护自己的窗体发一条 WM_QUERYENDSESSION，
返回 0 且标记写入；不真关机）。defect-audit 344/344。

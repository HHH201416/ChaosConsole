## 打包

`npm run dist` → `release/ChaosConsole-Setup-10.0.1.exe`（92.28 MB），
`latest.yml` version=10.0.1，manifest.json sha256=d7634aceb68c…。

**新坑**：vite 构建时清空 `dist/assets`（52 个文件）触发沙箱 safe-delete 的
`SAFE_DELETE_BULK_CONFIRM_REQUIRED`（阈值 50），导致 `npm run dist` 直接失败。
解决：打包前先用 PowerShell `Remove-Item dist -Recurse -Force` 清掉产物目录，
再跑 dist（目录不存在就不会触发批量删除）。单独 `build:web` 因为文件数未过阈值可能不报，
但反复构建后会累积——**以后发版前先手清 dist**。

## 10.0.2：卸载程序（用户要求「下载即含、可随升级安装」）

**需求**：安装包自带卸载程序；卸载时可选删数据（用户选「默认删除、可勾选保留」）；
设置里能一键调起；覆盖安装 10.0.2 即换上新卸载器。

**实现**
- `build/uninstaller.nsh`（新建，UTF-8 BOM）：`customUninstallPage` 钩子插一页
  nsDialogs 选项页，复选框默认勾选「同时删除用户数据」，取消则保留。
  删除在页面 Leave 里执行；`customUnInstall` 只做无条件清理（Run 注册表项）。
- 清理范围：`%APPDATA%\chaos-console`、`%APPDATA%\chaosconsole`（8.x 旧名，本机
  实测确实存在）、`%LOCALAPPDATA%` 下两个同名目录；不碰 `.ollama`。
- `electron/main.js`：`app:uninstall` IPC，按 productName 多候选探测 Uninstall exe，
  系统确认框 → 延迟 2 秒拉起 → app.quit()。**必须应用先退**，否则卸载器
  `checkAppRunning` 会中止。
- 设置 → 桌面集成 → 「卸载应用」（`UninstallField`），绿色版提示「直接删文件夹」。
- 版本 10.0.2，三处特性说明齐（changelog / release-notes-10.0.2.md / defect-audit）。

**两个 NSIS 坑（连挂两次构建，务必记住）**
1. **卸载器里必须写 `UninstPage`，不能写 `Page`**。写 `Page` 时页面不会登记进
   卸载页面栈，页面函数同时被判「未引用」→ `warning 6010`，而 electron-builder
   把 warning 当错误，报 `Error: warning treated as error`。报错信息只说函数没被
   引用，**不提 Page 写错了**，极易误判成「钩子没生效」而去换钩子（第一次就这么
   绕了一圈）。
2. Function 与页面定义必须**整段包在宏体内**：自定义 include 落在 common header
   （MUI2 之前），`MUI_HEADER_TEXT`/nsDialogs 到页面列表处才存在。

**其他**
- `.gitattributes` 加 `build/*.nsh -text`：这些文件靠 BOM 判编码，别让换行符
  转换动它们。
- 静默卸载 `/S` 不显示页面，`$ChaosUnDelData` 为空 → 不删数据（刻意的安全默认）。

**验证**：defect-audit 365/365、regress 50/50、regress-v8 64/64、i18n 357/357、
NSIS 编译通过，产出 `ChaosConsole-Setup-10.0.2.exe`（92,286,168 B）。

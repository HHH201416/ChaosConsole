## 打包

`npm run dist` → `release/ChaosConsole-Setup-10.0.1.exe`（92.28 MB），
`latest.yml` version=10.0.1，manifest.json sha256=d7634aceb68c…。

**新坑**：vite 构建时清空 `dist/assets`（52 个文件）触发沙箱 safe-delete 的
`SAFE_DELETE_BULK_CONFIRM_REQUIRED`（阈值 50），导致 `npm run dist` 直接失败。
解决：打包前先用 PowerShell `Remove-Item dist -Recurse -Force` 清掉产物目录，
再跑 dist（目录不存在就不会触发批量删除）。单独 `build:web` 因为文件数未过阈值可能不报，
但反复构建后会累积——**以后发版前先手清 dist**。

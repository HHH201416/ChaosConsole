Features

8.0.0 新增了什么

从更快地找到任务，到更稳地管好数据：这一版把日常操作里的摩擦点逐一补上。

命令面板

Ctrl+K 打开全局搜索，快速跳转任务、岗位、设置和常用动作，不用在多层菜单里找。

任务模板

把常用的标题、描述、标签、执行器、模型和流水线保存成模板，下次一键套用。

批量操作

在看板中多选任务，批量启动、取消、完成、移动或删除，整理积压任务更快。

任务依赖

给任务设置前置依赖；依赖未完成时不会派单，完成后自动继续，卡片上会显示阻塞数量。

派单策略

支持关键词匹配、最少忙碌、轮询三种策略，可按团队习惯选择新任务交给谁。

流水线编辑器

用可视化编辑器调整阶段与岗位的对应关系，方案、编码、构建、测试按你的流程接力。

导出 / 导入

把岗位、任务、对话、事件和模板导出为 JSON，换机或重建工作区时一键导入。

自动备份

支持自动与手动备份、恢复和保留策略；恢复前会先停掉运行中的任务，避免数据写坏。

统计面板

查看任务总量、完成率、阻塞数、执行器分布和阶段耗时，纯本地 SVG 绘制，不依赖外部图表库。

健康诊断

一键检查数据库、执行器、工具链和配置，导出诊断包，定位问题时不用靠猜。

托盘与通知

关闭窗口可最小化到系统托盘；任务完成或需要回复时发送通知，并可设置为仅窗口不在前台时提醒。

中英双语

界面静态文案支持中文和 English 即时切换，语言选择保存在本机。

主题强调色

在深色 / 浅色主题之外，还能选择不同的强调色，让控制台更符合你的习惯。

工具链安装器

检测 Node.js、Claude Code CLI、DevEco Code CLI 和 DevEco Studio，缺什么就按引导安装。

Install

四步装好

下载到的是 Windows 安装向导，不需要预装 Node.js，也不需要配置开发环境。

  1. 1

    下载安装包

    选择 GitHub 或 Gitee 线路，下载 .exe 安装文件。浏览器若询问是否保留，选择保留。

  2. 2

    双击运行

    若出现蓝色的「Windows 已保护你的电脑」，点 更多信息 → 仍要运行。这是未签名程序的常见提示，原因见下方。

  3. 3

    选择「仅为我安装」

    后续升级和回退更安静，不需要每次确认权限。选择「为所有人安装」则每次更新都可能弹出 UAC。

  4. 4

    启动并开始使用

    首次启动会补齐岗位名册。之后有新版本时，程序内会提示更新。

关于 SmartScreen 警告

安装包没有购买代码签名证书，Windows 会对未签名、下载量较少的 exe 显示蓝色警告。这与程序是否有问题无关。更稳妥的做法是先按 SHA-512 / SHA-256 核对文件，再决定是否运行。

如何核对哈希

在 PowerShell 中运行以下命令，把输出与页面上的 SHA-256 比对；也可以把 SHA256 换成 SHA512。

PowerShell 示例
Get-FileHash .\ChaosConsole-Setup-<version>.exe -Algorithm SHA256

旧系统也可以用：certutil -hashfile <安装包路径> SHA256

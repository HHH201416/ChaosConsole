Features

它到底替你做了什么

核心是一件事：让多个 AI 岗位像一支队伍那样接力干活，而不是丢给一个对话框反复重来。

21 个岗位分工

11 个 Claude 岗 + 10 个 DevEco 岗。关键词自动派单，没命中就兜底给「日常对话」，不用你手动挑人。

跑挂了能中途换岗

任务失败或超时会自动换一个岗位接手，另配四道护栏，避免它在两个岗位之间来回踢皮球。

四阶段流水线

方案 → 编码 → 构建 → 测试，每一阶段的产出交给下一个岗位，过程在界面上可见。

MCP 按岗位挂载

每个岗位只挂它该用的工具。写代码的岗位拿不到发布权限，减少「手滑改坏别的东西」。

下载加速 + 完整性校验

更新走镜像，约 20 秒装完。校验值只从 GitHub 官方接口取，对不上就删文件报错，不装。

一键回退任意版本

设置里列出全部历史版本，新版不满意可以直接退回旧版，退回后程序会自动重新拉起来。

Install

装起来四步

下载完是个 .exe 安装向导，全程点几下就行，不需要装 Node、也不需要配置环境。

1

下载安装包

点上面的按钮，得到一个约 86.9 MB 的 .exe。浏览器可能会先问一句「是否保留」，选保留。

2

双击运行

如果弹出蓝色的「Windows 已保护你的电脑」，点更多信息 → 仍要运行。原因见下方说明。

3

选「仅为我安装」

这样后续升级和回退都是静默的，不会再弹权限确认框。选「为所有人安装」则每次更新都要点一次 UAC。

4

启动即可用

第一次打开会自动把岗位名册补齐。以后有新版，程序内直接提示更新。

关于那个蓝色警告：这个安装包没有买代码签名证书（一张证书一年要几百到几千块），Windows 对没有签名、又没被下载过几次的 exe 一律会弹这个提示，和程序本身有没有问题是两回事。想更稳妥的话，可以按上面的 SHA-512 自己核对一遍文件再装。

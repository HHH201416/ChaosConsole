# ChaosConsole 8.0.0

8.0.0 是 **完好版**：7.6.8-beta / 7.6.9-beta 里故意注入的 66 个缺陷已全部清除，
并在此基础上补齐了运行环境安装、官网和数据工具。

## 修复

- 启动 / 登录：闪屏与启动屏时长、密码框、回车提交、布局错位全部恢复。
- UI：任务计数、连接状态颜色、下载进度、忙碌统计、状态色、拖拽高亮、字号/间距、
  弹窗高度、主题选中态全部修正。
- 功能：Toast 自动消失、重试上限、退出清 token、派单优先级、流水线覆盖顺序、
  空闲岗位选择全部修正。
- 稳定性：移除了所有随机失败、随机断线、随机丢弃推送、随机 API 延迟。

## 运行环境 / 工具链（新）

- 自动检测 Node.js、Claude Code CLI、DevEco Code CLI、DevEco Studio。
- 缺失时可在应用内一键安装，全程显示进度与日志，可取消。
- Node/CLI 安装到应用自己的目录，不修改系统 PATH；DevEco Studio 走 winget，
  需要 UAC 与华为账号，失败会回退到官方下载页。
- 绝不会静默安装或静默提权。

## 新功能

- 命令面板 / 全局搜索（Ctrl+K）
- 任务模板
- 批量选择与批量操作
- 快捷键帮助（Ctrl+/ 或 F1）
- 任务依赖 / 子任务，依赖未完成时不会派单
- 自动派单策略：按内容 / 最闲优先 / 轮流
- 流水线可视化排序编辑
- 工作区导出 / 导入
- 自动备份与恢复（默认每日，保留 10 份）
- 统计仪表盘
- 健康诊断与诊断包导出
- 系统托盘 + 原生通知
- 全局显示/隐藏快捷键
- 中英双语界面
- 强调色预设（橙 / 天蓝 / 紫 / 翠绿）
- 检查历史版本时提示 Watt Toolkit（可关闭 / 不再提示）

## 官网

- 中英双语、移动端导航。
- GitHub Releases + Gitee 双下载源，SHA-512 / SHA-256 校验信息。
- 数据由 `release/manifest.json` + GitHub/Gitee 元数据统一生成，GitHub Actions
  自动部署到 GitHub Pages。

## 升级说明

- 7.6.3 / 7.6.8-beta / 7.6.9-beta 可直接检查更新到 8.0.0。
- 数据库只做增量迁移，旧数据保留；导入/恢复前会自动备份。
- 安装包仍未签名，Windows SmartScreen 可能提示；请用官网提供的 SHA 校验安装包。
